# 12 周 GitHub 与现代编程学习仓库

每周 8–10 小时，项目驱动。完成后在下方打勾，并把每个产出放进对应目录。

## 进度

### 阶段 1：Git 与 GitHub（`phase1-git/`）
- [ ] W1 Git 基础：init/add/commit/branch/merge/rebase/stash（learngitbranching.js.org）
- [ ] W2 GitHub 协作：Fork、PR、Issues、Review、Projects（skills.github.com）
- [ ] W3 命令行、`gh` CLI、SSH key、Markdown
- [ ] 产出：Profile README + 1 个开源文档 PR

### 阶段 2：核心编程（`phase2-programming/`）
- [ ] W4 Python/TypeScript 语法、数据结构、虚拟环境/npm
- [ ] W5 算法（LeetCode Easy 20 题）、调试、pytest/Vitest
- [ ] W6 HTTP/REST、JSON、异步、SQL
- [ ] 产出：带测试的 CLI/爬虫/数据处理项目

### 阶段 3：工程实践（`phase3-engineering/`）
- [ ] W7 React + Next.js 或 FastAPI、Tailwind
- [ ] W8 GitHub Actions、Dependabot、分支保护、Secrets
- [ ] W9 Docker、云部署（Vercel/Render/Cloudflare）
- [ ] 产出：全栈应用 + CI + 线上地址

### 阶段 4：AI 与安全（`phase4-ai/`）
- [ ] W10 Copilot（Chat/Agent/CLI）、提示词、验证 AI 代码
- [ ] W11 LLM API、RAG、向量库、MCP、Agent
- [ ] W12 OWASP、CodeQL、Secret scanning、系统设计
- [ ] 产出：AI 应用 + README + CI + 部署

## 持续习惯
- 每日：提交代码；读 GitHub Trending
- 每周：读 1 个开源项目源码；在 `notes/` 写 1 篇笔记
- 每月：1 次开源贡献（`good first issue`）

## 开始
```bash
cd learn-github-12w
git init && git add . && git commit -m "init: learning plan"
gh repo create learn-github-12w --public --source=. --push
```
